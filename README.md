# Mean Green Racing

Website for UNT Society of Automotive Engineers, built with _sveltekit_.

# Build

To create the site, run this command:\
`npm run build`

This will create a folder `build`, wherein all the static HTML, CSS, and Javascript files will be found.

# Layout

There are currently 7 sites:
* Home
* History
* Cars
* Senior Spotlight
* Senior Designs
* Members
* Sponsors

# Photos

Most of the media, including what you see on the hero component, the member headshots, and the media page,
are stored in the `Mean Green Racing oneDrive`.

The links are found by selecting the image in OneDrive, selecting "Embed," copying the link found in "src," and replacing "embed" with "download"
